# 直排輪互動學習教材

繁體中文直排輪初學者互動教材，包含 8 階段學習歷程、T 字煞車與進度記錄。

網站首頁為 `index.html`。完整動作圖解應放在 `assets/` 資料夾：

- `assets/safe-fall-and-recovery.png`：安全跌倒與起身
- `assets/braking-techniques.png`：煞車技巧完整圖解
- `assets/t-stop-steps.png`：T 字煞車動作分解

GitHub Pages：在 Settings → Pages → Build and deployment 選 Deploy from a branch，選 `main`、`/(root)`，儲存。網址為 https://YUAN-5149.github.io/inline-skating-learning/ 。
